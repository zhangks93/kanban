# 工作台界面规范

工作台采用浅色中性背景、白色面板和绿色重点操作，围绕“找到工作空间 → 查看任务 → 理解详情 → 完成操作”组织层级。Shell、页面骨架和业务区域各有明确的实现位置，新增页面应复用已有布局及视觉 token。

## 五档字号

字体统一来自 `apps/web/src/styles/tokens.css`，仅使用下列五个字号。字重、颜色、间距与层级共同表达重要程度，不再为每个功能增加新的字号。

| Token       | 字号 | 角色                                 |
| ----------- | ---- | ------------------------------------ |
| `--font-xs` | 12px | 辅助说明、状态、时间、编号和等宽信息 |
| `--font-sm` | 13px | 字段标签、紧凑控件、元数据           |
| `--font-md` | 14px | 正文、导航、卡片标题、输入内容       |
| `--font-lg` | 18px | 页面分节、弹窗标题                   |
| `--font-xl` | 24px | 页面标题、关键统计、品牌             |

表单提示通过标签、说明和错误信息区分；颜色不承担唯一含义。标题用语义化 `h1`／`h2`，不根据元素所在页面随意更改字号。

颜色使用 `--bg`、`--surface`、`--panel`、`--text`、`--muted`、`--border`、`--accent`、`--accent-soft`、`--danger`。间距、圆角和阴影由 token 统一维护；领域样式只处理布局和该领域必要的状态。`focus-visible` 提供键盘焦点，减少动态效果偏好继续生效。

## Shell 与导航

`layouts/AppShell.tsx` 负责当前身份、工作空间查询、应用上下文和登录生命周期。`layouts/WorkspaceNavigation.tsx` 渲染工作空间切换、分组导航及个人菜单；`layouts/navigation.ts` 集中定义导航与当前位置解析。路由配置保留在 `routes/router.tsx`，避免把应用 Shell 与所有页面路由写在同一个组件里。

导航按照任务关系分组：个人工作、空间协作、当前空间看板、管理、集成与访问。管理项按现有角色显示；显示或隐藏导航不替代服务端权限检查。当前项使用路径段准确匹配与 `aria-current`，桌面显示工作空间／看板路径，移动端显示当前页面标题。

桌面 Shell 使用 56px 顶栏、240px 导航区和 56px 工作空间轨道。900px 以下切换为 48px 移动顶栏与导航抽屉。抽屉与桌面复用相同的导航内容，支持关闭按钮、遮罩、Escape、Tab 焦点约束和关闭后的焦点返回；背景内容使用 `inert` 防止键盘误入。公开分享不进入登录 Shell，Agent 授权登录保留原用户码。

## 页面骨架

共享组件位于 `components/PageLayout.tsx`：

| 组件          | 用途                                                |
| ------------- | --------------------------------------------------- |
| `PageHeader`  | 页面标题、说明、上层提示和主要操作                  |
| `PageSection` | 一组有标题／说明的相关内容及分组操作                |
| `EmptyState`  | 无结果、加载和错误反馈；错误用 alert，加载用 status |
| `StatCard`    | 一个统计值、名称及辅助解释                          |

普通页面采用 `.page-layout`，以页面标题开头，再放筛选工具栏、统计或内容分组。主操作放在页头或对应分组，不把同级按钮散布到无关位置。管理列表使用语义化表格和横向溢出容器；长字段保持可读，不靠缩小字体容纳。640px 以下表单、统计和卡片按单列展开，操作允许换行。

空状态应说明当前范围和下一步；错误展示实际失败并允许合适的重试。没有读到数据时不能显示成功信息或凭空填充统计。授权页面按“发起 CLI 授权 → 用户确认 → 管理已有授权”组织，清楚显示客户端、工作空间、范围、到期时间和撤销入口。

## 领域样式归属

`styles/workbench.css` 只负责导入；样式按照功能归属维护：

| 文件             | 所属内容                                           |
| ---------------- | -------------------------------------------------- |
| `tokens.css`     | 字号、颜色、间距、圆角、基础控件和全局可访问性规则 |
| `components.css` | 共享组件与页面骨架                                 |
| `shell.css`      | Shell、导航、顶栏和移动抽屉                        |
| `pages.css`      | 通用页面、登录和页面级布局                         |
| `board.css`      | 看板、筛选工具栏、泳道、列和虚拟列表布局           |
| `tasks.css`      | 任务卡片、快捷预览、完整详情与表单                 |
| `my-work.css`    | 个人工作、WIP 与替换流程                           |
| `management.css` | 空间、看板、成员、插件等管理区域                   |
| `work-logs.css`  | 工时记录与统计                                     |

`agent-access.css`、`foundation-data.css` 和 `sharing.css` 继续归各自功能。新样式写入所属模块，不在文件尾部增加重复覆盖层，也不靠更高选择器权重补丁修正基础规则。

## 看板与验证

看板保留横向任务列和其业务交互；标题区 56px、筛选区 48px，滚动区域扣除 Shell 顶栏高度。任务卡片保留 103px 最小高度，虚拟列表继续测量实际行高；修改文字密度时需要同时观察滚动、预览和完整详情。

界面变更应检查桌面与移动端、长标题、无结果、错误、键盘焦点、管理表格溢出以及 Agent 授权码往返。字号可以静态检查 token 使用，浏览器验证仍需覆盖真实宽度和实际内容。视觉基线有变化时应先复核，再决定是否更新截图，不能用更新基线掩盖交互回归。
